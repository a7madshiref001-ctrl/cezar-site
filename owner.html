النشر على الموقع

التعديلات بتتحفظ في المتصفح لحد ما تنشر. بعد النشر الموقع بيتحدّث خلال دقيقة تقريبًا.

التوكن بيتحفظ في المتصفح ده بس، وبيتبعت لـ GitHub وخلاص — عمره ما بيدخل جوه الموقع. متفتحش اللوحة على جهاز مش بتاعك، ولما تخلّص اضغط «نسيان التوكن».
إزاي أعمل توكن؟
  1. افتح github.com/settings/personal-access-tokens واختار Fine-grained token.
  2. في Repository access اختار Only select repositories والمستودع بتاع الموقع بس.
  3. في Permissions ← Repository permissions ← Contents خلّيها Read and write. مش محتاج أي صلاحية تانية.
  4. حطّ له تاريخ انتهاء، اعمله Generate، وانسخه هنا.
