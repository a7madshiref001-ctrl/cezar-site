# عقد الربط المقترح لسيستم الجيم

هذا عقد **افتراضي للتجربة والتجهيز**، وليس توثيقًا لسيستم الجيم الفعلي. التنفيذ النهائي
يحتاج اسم المنتج أو وثائقه وعينة استجابة حقيقية وصلاحية API من مالكه. لا تفعّل
`GYM_API_MODE=http` على الإنتاج قبل مطابقة الحقول والمسارات وتأكيد سلوك التكرار.

## الاتصال

- عنوان أساس `https://...` في `GYM_API_BASE_URL`؛ مفتاح سري في `GYM_API_KEY` على الخادم فقط.
- كل طلب يحمل `Authorization: Bearer <key>`؛ مهلة 5 ثوانٍ؛ لا تُتبع إعادة التوجيه.
- لا يوجد اتصال مباشر بين متصفح العضو والسيستم الخارجي؛ لا تُرسل الأسرار للعميل.

## المطلوب من السيستم

| العملية | المسار | المطلوب |
|---|---|---|
| تأكيد هوية عضو | `GET /members/{external_member_id}` | `{ "id": "gym-9", "name": "...", "phone": "01..." }` |
| قراءة اشتراك وحضور | `GET /members/{external_member_id}/dashboard` | `memberships[]` كما في المثال |
| إنشاء اشتراك | `POST /memberships` | يستقبل البيانات أدناه، ويرد `{ "id": "external-plan", "member_id": "gym-9" }` |

مثال `dashboard`:

```json
{
  "memberships": [{
    "id": "external-plan-1",
    "plan_name": "جولد",
    "total_sessions": 24,
    "used_sessions": 6,
    "starts_at": "2026-09-01T00:00:00+03:00",
    "ends_at": "2026-10-01T23:59:59+03:00",
    "attendance": [{"id":"visit-1", "checked_in_at":"2026-09-27T18:14:00+03:00"}]
  }]
}
```

طلب إنشاء الاشتراك يحتوي `source=cezar-web` و`source_membership_id` و
`source_order_id` (قد يكون `null`) و`member` (`name`, `phone`) و`plan`
(`name`, `total_sessions`, `starts_at`, `ends_at`). يجب أن يحترم السيستم ترويسة
`Idempotency-Key` التي تحمل `source_membership_id`، وأن يعيد نفس النتيجة في
إعادة المحاولة بدل إنشاء اشتراك ثانٍ.

## سلوك الموقع

1. الإدارة تراجع الطلب وتفعّل الاشتراك. الدفع التجريبي **لا** يفعّل تلقائيًا.
2. تُحفظ محاولة الإرسال بحالات `pending` أو `sent` أو `error`. الفشل لا يخفي
   الاشتراك المحلي، لكنه يطلب من الإدارة إعادة المحاولة بعد إصلاح الربط.
3. عضو السيستم الموجود يمكن ربطه بعد مطابقة رقم موبايله مع استجابة API. ينشأ
   رمز دخول جديد فقط إن لم يكن له حساب سابق على الموقع.
4. العضو المربوط يقرأ الحصص والحضور من API مباشرة. عند الانقطاع تظهر آخر نسخة
   محفوظة بتحذير وتاريخ تحديث، أو حالة تعذّر العرض إذا لم توجد نسخة.
5. تسجيل الحضور المحلي لعضو مربوط ممنوع؛ السيستم الخارجي هو مصدر الحقيقة.

## قبل التشغيل الحقيقي

- أكّد المسارات وطريقة التوثيق والحقول من وثائق مزود سيستم الجيم.
- أكّد صلاحيات المفتاح: قراءة أعضاء/اشتراكات/حضور وإنشاء اشتراك فقط.
- اختبر تكرار الطلبات، الانقطاع بعد نجاح الإرسال، حالات انتهاء الباقة، والتوقيت المصري.
- اتفق على طريقة آمنة لتسليم رموز دخول الأعضاء، ولا ترفع أي أسرار إلى GitHub.
